faxe1008 DWM custom build
=========================

Features
--------

* swallowing
* ssh aware spawning of new clients
* opacity on a per client basis
* joypixel font support
* load colours from ~/.Xresources
* excepting signals using xsetroot
* vanitygaps
* layouts: tile, centeredmaster, floating, bstack, spiral, deck
* stacker for shifting master
* true fullscreen
* activetagbarindicator

Dependencies
-------------

* ttf-joypixels (emoji support)
* libxcb (swallowing)
* Xlib-libxcb (swallowing) 
* xcb-res (swallowing)
* libprocps (ssh awareness)
* libxft-bgra (emoji support)

Besides those hard depedencies, this build uses alacritty as a terminal emulator.
